RAJA OLEH-OLEH

Website Raja Oleh-Oleh dibuat sebagai proyek untuk menampilkan informasi dan katalog produk oleh-oleh secara online.

Teknologi yang Digunakan

- PHP
- HTML
- CSS
- JavaScript
- MySQL/MariaDB
- XAMPP
- Visual Studio Code

Struktur Folder

- "assets/images/" → menyimpan foto produk dan logo.
- "assets/js/" → menyimpan file JavaScript.
- "config/" → menyimpan koneksi database.
- "database/" → menyimpan file database "raja_oleh_oleh.sql".
- "includes/" → berisi "header.php", "navbar.php", dan "footer.php".
- "views/" → berisi halaman website seperti Home, Produk, Detail Produk, Tentang, Kontak, Beli, dan Daftar Pesanan.
- "index.php" → file utama website.

Database

Nama database:

"raja_oleh_oleh"

Tabel yang digunakan:

- "produk"
- "artikel"
- "pesan"
- "pesanan"

File database terdapat di:

"database/raja_oleh_oleh.sql"

Aset Website

Foto produk dan logo Raja Oleh-Oleh disimpan di:

"assets/images/"

Menjalankan Website

1. Jalankan Apache dan MySQL melalui XAMPP.
2. Pastikan database "raja_oleh_oleh" tersedia di phpMyAdmin.
3. Simpan folder "raja_oleh_oleh" di dalam "htdocs".
4. Buka website melalui browser menggunakan "localhost".
